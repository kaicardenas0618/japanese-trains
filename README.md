# Subway Builder Japanese Trains

Subway Builder Japanese Trains is a mod for Subway Builder that adds trains from cities around Japan. All available train and track options are listed below.

## Track Types

This mod uses a proprietary track and train separation system that allows every compatible train to run on every compatible track, allowing for easy through running and track type management when building recreations of existing systems. Each line has its own track type, named `{gauge}{line code}-{speed}`.
Initial builds should be done with a track option where applicable. Compatible tracks are listed at the end of the train name, e.g. both JP N700A Shinkansen 1435JP and JP E5 Shinkansen 1435JP are compatible with 1435JP-60, 1435JP-100, 1435JP-130, 1435JP-285, 1435JP-320, and 1435JP-360 tracks. Specific trains can be chosen afterwards in the route menu.

## Capacity

Capacity per car is calculated from each car's floor area rather than manufacturer figures:

`capacityPerCar = ((carLength x trainWidth) - (seatsPerCar x 0.215)) x C + seatsPerCar`

0.215 m2 is the floor space taken up by each seat, and C is the standing density in passengers per m2:
- C7: metro, including trains that run through onto subway lines
- C6: inner suburban
- C5: commuter
- C4: tram, people mover and monorail

Each train's C value is listed at the end of its description. Limited expresses, expresses and Shinkansen use their seat count as their capacity per car instead.
